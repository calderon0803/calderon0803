# Carlos Calderón

Desarrollo interfaces web con Vue 3. Trabajo sobre todo con datos científicos y
medioambientales: visores de series temporales, mapas y paneles de análisis que
tienen que seguir siendo rápidos y legibles cuando el volumen crece.

Me interesa el punto exacto donde el frontend se cruza con los datos. Y el código
que sigue entendiéndose seis meses después.

## Herramientas

Vue 3 con Composition API y `<script setup>`, TypeScript, Vite y Pinia. Quasar y
SCSS con tokens de color para la interfaz. Plotly para los gráficos. Vitest,
Vue Test Utils y Playwright para las pruebas. Accesibilidad según WCAG 2.1.

## Ahora mismo

Mantener fluida la visualización interactiva cuando el volumen de datos crece,
cuidar el rendimiento de carga, y afinar mis convenciones de componentes para que
el código se lea igual de bien dentro de unos meses.

## Fuera del trabajo

Deporte, coleccionismo, y anime y manga.
